# Windows Sandbox 受控计算实施计划

1. 先为计算运行器、沙盒配置/启动器和输出采集写失败测试；所有测试临时目录固定在 F 盘。
2. 增加 F 盘只读运行时定位、每次运行的输入快照、只读映射、独立可写输出映射、关闭网络的 `.wsb` 生成和沙盒生命周期管理。
3. 实现启动预检、受限 stdout/stderr、300 秒超时、Windows Sandbox 2 GiB 最低内存配置、取消和 teardown；任一隔离条件不满足时保持 fail-closed。
4. 把模型声明的输出计划传给运行器；验证 CSV/PNG 名称、类型、内容和大小后再原子登记结果证据，并保留现有 `ResultValidator`。
5. 将运行器装配到 `main_window`，让“运行与审核”显示 Sandbox 能力/当前运行状态和清晰错误；检查恢复、取消、重复投递及旧运行检查点行为。
6. 锁定并打包 CPython 与数模常用运行库；构建、清单/路径扫描和源程序启动验证均使用 F 盘临时与输出目录。
7. 在 Windows Sandbox 中执行合成数据的单元/集成验收，再从发行 EXE 通过计算和结果验证阶段。保留原有 dirty worktree，只提交本任务命名的源码、测试和验收文档变更，不改用户数据、不推送。
