## 1. 目标与已批准方向

将数模论文工作台的现有 PySide6 界面完整改为 Fluent 风格，参考 zhiyiYo/PyQt-Fluent-Widgets 的导航、层级、控件与反馈设计。保留当前产品用途：个人 Windows 单机上管理数模项目、导入题目与数据、映射 Word 模板、审核 Agent 运行并查看产物。

用户已选择完整改版。此规格限定为界面与交互呈现改造，不扩大为业务流程或 API 行为变更。

## 2. 当前界面与技术基线

- 项目运行时使用 PySide6 6.8.2.1；界面代码分布在 main_window.py、project_wizard.py、template_mapping_view.py、run_panel.py、run_review.py、settings_view.py。
- 主窗口当前以左侧项目列表加顶部四个标签页组织：项目与数据、Word 模板、运行与审核、设置。
- 工作流、项目存储、文件范围校验、模板映射、预运行范围/费用确认、取消与恢复均由现有控件信号和服务逻辑承载。
- Windows 打包入口通过 scripts/verify_f_drive_outputs.py 的 launch_desktop 创建 QApplication 和 MainWindow；python -m mathmodel_paper_studio 仍是早期存储检查器。
- 当前 pyproject.toml 只声明 PySide6，没有 Fluent Widgets 依赖。打包依赖由 requirements.lock 和 PyInstaller 规格共同约束。

## 3. 设计方案

### 3.1 主窗口与导航

- 使用与 PySide6 兼容的 Fluent Widgets 发行版和 Fluent 主窗口导航。不得将 PyQt5/PyQt6 绑定与现有 PySide6 进程混装。
- 将顶部 QTabWidget 改为左侧 Fluent 导航，保留四个主要位置：项目与数据、Word 模板、运行与审核、设置。设置放在导航底部或分组末端。
- 活动项目名称、项目状态和数据根目录在页面标题区清晰显示。项目列表收纳在“项目与数据”页面，避免形成两条相互竞争的主导航。
- 页面切换保持现有页面实例或兼容适配层，使运行状态、当前项目和未完成操作不因切换页面而丢失。

### 3.2 页面层级

- 项目与数据：以页面标题、项目选择/新建操作、题目、数据摘要、输入文件和产物检查卡片组织内容。主要动作“新建项目”“审核本次运行范围”突出；未选择项目时显示明确空状态和可执行动作。
- Word 模板：把当前模板状态、模板选择、章节映射、未支持结构说明和保存动作分成清楚区块；映射较长时允许滚动，保存状态在操作附近显示。
- 运行与审核：顶部突出所选 Agent 和运行状态；审核内容、阶段进度/事件、取消/继续操作和产物入口分层显示。费用与外发范围仍在开始前审核界面展示。
- 设置：使用分组卡片呈现数据目录、Agent 选择和当前预检状态；API Key 继续只从环境读取，不在设置页显示或保存密钥。
- 新建项目、运行审核和结果审核对话框沿用原有流程，以 Fluent 控件统一输入、按钮、错误、加载和确认样式。

### 3.3 视觉与交互规则

- 默认跟随 Windows 的浅色/深色系统主题；保持中文文案、Windows 高 DPI 可读性、键盘焦点提示和足够的文本对比度。
- 统一页面边距、卡片间距、标题层级、主次按钮、状态色与图标；图标使用 Fluent 图标，不以 emoji 代替功能图标。
- 加载、禁用、成功、警告、错误、取消中和暂停状态都提供文字反馈；关键反馈放在相关控件或内容区附近。
- 维持紧凑但不拥挤的桌面布局；窗口缩窄时控件可换行或滚动，不隐藏主操作，也不产生水平溢出。

## 4. 兼容性和业务边界

界面改版不得改变：

- AppPaths 的 F: 路径策略、数据库结构、项目文件布局、导入副本和原始文件保护规则。
- 现有 provider 选项、运行前数据范围说明、DeepSeek 费用授权与撤销规则、Codex 状态提示。
- 工作流阶段、运行取消/恢复、模板映射数据格式、DOCX 写入和质量检查逻辑。
- 已有对象名、信号/槽和模型访问语义；如 Fluent 控件的方法签名不同，添加薄适配器以维持现有调用语义。
- 原有页面和对话框的用户可见操作。只调整导航与展示组织，不静默删除功能。

## 5. 依赖、打包与授权

- 使用 PySide6 专用的 Fluent Widgets 包/分支，不安装 PyQt 绑定。实施前核对与 PySide6 6.8.2.1、Python 3.13、Windows 和 PyInstaller 的兼容版本，并固定锁文件及哈希。
- 更新 PyInstaller 收集规则和许可证清单，确认 Fluent 字体、图标、主题资源在 onedir 包中可用。
- 官方仓库 README 将该库列为 GPL-3.0 非商业用途，并要求商业用途获取商业许可。当前产品范围是个人 Windows 单机；若后续变为商业或闭源分发，发布前必须重新审查授权。
- 新构建输出使用单独的 F: 下载/发布目录，不覆盖旧预览包；构建缓存和临时目录均留在 F:。

## 6. 验收标准

- 界面进入后可见 Fluent 主窗口、左侧导航和正确的四个中文页面；当前项目和运行状态在页面切换后保持一致。
- 项目创建、数据/模板选择、章节映射保存、运行审核、费用/范围披露、取消/继续、产物打开和设置选择仍可由界面完成。
- 空状态、后台加载、错误、暂停和成功状态都有可辨识的文字与控件反馈；主要控件可用键盘操作。
- 在常见桌面分辨率和 Windows 125%/150% 缩放下检查页面无截断、遮挡或水平溢出；浅色/深色主题下文字和控件均可辨认。
- 更新后的 onedir EXE 能从独立 F: 输出目录启动；旧预览包、用户数据、API 密钥和桌面快捷方式不被本次界面构建静默覆盖或迁移。
- 视觉验收、自动化界面契约、打包启动和业务服务证据分开记录，不以源码截图或单元检查代替可见桌面验收。
